# Getting help

sdlc-agent is maintained by volunteers. There is no paid support and no response-time promise, but we try to help.

| You want to… | Go to |
| --- | --- |
| Ask how to install, configure or use it | [Discussions → Q&A](https://github.com/pjx16/sdlc-agent/discussions) |
| Report a bug | [A bug report issue](https://github.com/pjx16/sdlc-agent/issues/new?template=bug_report.yml) |
| Suggest a feature | [A feature request issue](https://github.com/pjx16/sdlc-agent/issues/new?template=feature_request.yml), after checking the [scope](./README.md#scope-and-known-limitations) |
| Report a security problem | Privately, as described in [`SECURITY.md`](./SECURITY.md). Never in a public issue |

Before asking, please check the [README](./README.md), the [configuration reference](./docs/CONFIGURATION.md) and existing issues. `sdlc-agent doctor` checks a release install, and `sdlc-agent logs` shows what the services are doing.

When you ask, include your version (`sdlc-agent --version`), your OS and Docker version, what you did, what you expected and what happened. Redact tokens and private repository content from logs before you paste them.
