## Inputs

From the caller:

- the feature: a title and description, or an issue, with any requirements or
  acceptance criteria it already has
- a doc on that area of the code, if there is one
- the previous plan and what was wrong with it, if this is a second attempt

The repository, read-only.

## Result

The plan in the markdown structure above, then:

- **Risks:** one bullet each, or "none".
- **Open questions:** only the ones that change the plan, or "none".
